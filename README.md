## 日常办公原型

员工移动端提供「办事 / 对话 / 我的申请」三种视图，覆盖12类入口：

- 财务申请：费用报销、借款与备用金、付款申请。
- 假勤与人事：请假、加班/调休/考勤、证明与本人资料。
- 行政协作：商务合同、用印与授权、企业账号、物品与设备申领、设备报修、办公采办与验收。

新增事项接入共享待办、原始资料、确认字段和事项台账。审批、实际办理与本人接收分别记录；借款示例以财务核实归还到账后核销展示，物品和采办支持分批交付/接收。员工报修不直接取得报废处置权限，采购、合同和维修结果不自动触发真实付款。

## 内容维护

日常编辑这两份源文件：

- `企赢-系统原型.html`
- `企赢-产品方案与演示.html`

修改源文件后，运行下面的发布准备命令，再把变更提交到 `main`。GitHub Pages 会自动将 `docs` 目录发布到上面的固定网址。发布准备时自动转换页面文件名和相互链接，源文件继续保留中文名称。

本地检查发布文件：

```sh
python3 scripts/build_site.py
python3 -m http.server 8000 --directory docs
```

然后访问 `http://localhost:8000/`。

## 演示范围

页面内数据与办理记录均为样例；独立原型的交互进度仅保存在访问者当前浏览器中，不在访问者之间共享。语音、AI、税务、银行、合同签署与会计等外部服务尚未接入。

本仓库为公开演示项目，维护时只使用虚构或已脱敏资料。
