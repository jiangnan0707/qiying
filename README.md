## 内容维护

日常编辑这两份源文件：

- `企赢-系统原型.html`
- `企赢-产品方案与演示.html`

修改源文件后，运行下面的发布准备命令，再把变更提交到 `main`。GitHub Pages 会自动将 `docs` 目录发布到上面的固定网址。发布准备时自动转换页面文件名和相互链接，源文件继续保留中文名称。

本地检查发布文件：

```sh
python3 scripts/build_site.py
python3 -m http.server 8000 --directory docs
```

然后访问 `http://localhost:8000/`。
